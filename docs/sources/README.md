Check levels, used in every file:

- **A**: read in the paper's abstract or full text; the wording or number was confirmed.
- **B**: our own analysis of published data, or a value read off a published image with a scale bar.
- **S**: seen only in a search summary or a secondary page.
- **C**: textbook statement or remembered value; no source opened. Unverified.
- **D**: a drawing choice or assumption of ours.

These are working dossiers, copied as written. Paths such as `../analysis/…` and `../design/…` refer to internal notes that are not part of this repository; `yeast-jelly/…` means this repository. Corrections are welcome as issues.
